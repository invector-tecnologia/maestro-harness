# Maestro Documentation Hub

This directory is organized into four required areas:

1. [Maestro's Manifesto](Maestro_Manifesto/README.md): Philosophy, architecture doctrine, conventions, feature levels, and value streams.
2. [User's Manual](User_Manual/README.md): Command and panel reference for operators.
3. [Practical Guides](Practical_Guides/README.md): Hands-on guides for project setup and operational checks.
4. [Product's Engineering](Product_Engineering/README.md): Engineering roadmap, Product milestones, ADRs and release candidates.

**If you are new to the project** start with the [manifesto](Maestro_Manifesto/README.md), then follow the [practical guides](Practical_Guides/README.md).
